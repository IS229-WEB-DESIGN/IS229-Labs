IS229 Web Design · DevTools Guide
Browser Developer Tools

Your first debugging instrument

Do not guess. Use DevTools to inspect what the browser actually received, applied, executed and requested.

Elements

Inspect the live DOM, semantic structure, classes, attributes and accessible labels.

Use in labs: Weeks 02, 03, 06, 09.

Styles

See matched CSS rules, overridden declarations, box model and computed values.

Use in labs: Weeks 03-05, 09.

Console

Read JavaScript errors, log values and test small expressions.

Use in labs: Weeks 06-12.

Network

Inspect JSON requests, HTTP status codes, file paths and response content.

Use in labs: Weeks 08, 11, 13.

Responsive Mode

Test viewport widths and inspect whether the page overflows or controls become difficult to use.

Use in labs: Weeks 05, 09, 12.

Application / Storage

Inspect localStorage keys and values, then clear them to test default and recovery states.

Use in labs: Weeks 07 and 10.
Debugging sequence: reproduce the problem → read Console/Network → inspect the affected DOM/CSS → identify the smallest cause → change one thing → retest.

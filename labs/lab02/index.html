Key code reminder

Patterns to recognise

Pattern A · html
<header>
  <h1>Morobe Discover</h1>
</header>
<nav>...</nav>
<main>...</main>
<footer>...</footer>
Pattern B · html
<section class="hero">
  <h2>Discover Morobe</h2>
  <p>Find destinations, events and trip ideas.</p>
</section>
What to explain in code defence

Point to evidence

  1. <header>
    Identifies introductory content for the page or section.
  2. <nav>
    Groups the primary navigation links.
  3. <main>
    Contains the page's unique primary content; normally one main per page.
  4. <footer>
    Contains closing information such as project or contact details.
Rule: do not copy code you cannot explain. Be able to identify the file, the relevant line, the browser result and the user reason.

Before You Submit

Final checklist

Stuck?

Use a debugging sequence, not random edits

1. Read the browser console. 2. Confirm file paths. 3. Inspect the affected element in DevTools. 4. Reduce the problem to the smallest code pattern. 5. Compare with the Week 02 reference build. 6. Re-test one change at a time.

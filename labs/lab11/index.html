Key code reminder

Patterns to recognise

Pattern A · javascript
const matches = destinations.filter(item =>
  item.name.toLowerCase().includes(query)
);
Pattern B · javascript
results.innerHTML = matches.length
  ? matches.map(renderCard).join("")
  : "<p>No destinations found.</p>";
What to explain in code defence

Point to evidence

  1. filter
    Creates a new array containing only matching destinations.
  2. toLowerCase
    Normalises case so search is more forgiving.
  3. includes(query)
    Checks whether the destination name contains the search text.
  4. matches.length
    Determines whether there is at least one result.
  5. No destinations found
    Provides an explicit empty state instead of a blank interface.
Rule: do not copy code you cannot explain. Be able to identify the file, the relevant line, the browser result and the user reason.

Before You Submit

Final checklist

Stuck?

Use a debugging sequence, not random edits

1. Read the browser console. 2. Confirm file paths. 3. Inspect the affected element in DevTools. 4. Reduce the problem to the smallest code pattern. 5. Compare with the Week 11 reference build. 6. Re-test one change at a time.

IS229 Web Design · Debugging Lab
Debugging Lab

Find the cause before changing the code

Use the browser console, Elements panel, Styles panel and Network panel to reduce each problem to evidence.

Debug 01

HTML nesting

Broken example · text
<p><div>Destination</div></p>

Your task: Explain why this fails or behaves incorrectly, repair it, then state how you would test the repair.

A div cannot be a child of a paragraph. Use a div/article outside the p or keep phrasing content inside p.
Debug 02

Missing CSS selector

Broken example · text
card-grid { display:grid; }

Your task: Explain why this fails or behaves incorrectly, repair it, then state how you would test the repair.

A class selector needs a leading dot: .card-grid.
Debug 03

Flexbox not applied

Broken example · text
.site-nav { gap:1rem; }

Your task: Explain why this fails or behaves incorrectly, repair it, then state how you would test the repair.

gap does not create Flexbox by itself. Add display:flex (or another layout mode).
Debug 04

Responsive overflow

Broken example · text
img { width:1200px; }

Your task: Explain why this fails or behaves incorrectly, repair it, then state how you would test the repair.

A fixed image width can overflow small viewports. Use max-width:100%; height:auto.
Debug 05

DOM selector

Broken example · text
document.querySelector('#menu')
addEventListener('click', openMenu);

Your task: Explain why this fails or behaves incorrectly, repair it, then state how you would test the repair.

The event listener is not attached to the selected element. Store/select the element, then call element.addEventListener(...).
Debug 06

JavaScript syntax

Broken example · text
if (days < 1 { showError('Invalid'); }

Your task: Explain why this fails or behaves incorrectly, repair it, then state how you would test the repair.

The condition is missing a closing parenthesis before the opening brace.
Debug 07

JSON parse

Broken example · text
const data = JSON.parse('{name: Wau}');

Your task: Explain why this fails or behaves incorrectly, repair it, then state how you would test the repair.

Valid JSON requires quoted property names and string values: {"name":"Wau"}.
Debug 08

Fetch path

Broken example · text
fetch('/data/destinations.json')

Your task: Explain why this fails or behaves incorrectly, repair it, then state how you would test the repair.

On a GitHub Pages project site, a leading slash points to the domain root. Prefer a correct relative path such as data/destinations.json when appropriate.

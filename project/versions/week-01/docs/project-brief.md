# Morobe Discover - Project Brief

## Problem
Students need one coherent website through which they can learn and integrate HTML, CSS, responsive design, JavaScript, data, accessibility and deployment.

## Product
A fictional tourism discovery and sample trip-planning front-end website.

## Primary users
- Visitor exploring demonstration destinations
- Visitor building a sample trip estimate
- Student developer maintaining the project

## Core user stories
1. As a visitor, I want to browse destinations so I can compare options.
2. As a visitor, I want to estimate a trip so I can understand cost.
3. As a visitor, I want the site to work on my phone.
4. As a keyboard user, I want all controls to be operable without a mouse.

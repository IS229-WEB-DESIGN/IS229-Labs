IS229 Web Design · Course Roadmap
Course roadmap

One project. Thirteen deliberate increments.

Reading explains the idea → lecture demonstrates it → lab applies it → Morobe Discover integrates it into the same working website.

WeekTopic / TechnologyLearning outcomeProject evidenceLab
Week 01Project Discovery & Planning
PlanningGitMarkdown		Define the project problem, identify users/tasks, and structure the site architecture.Project brief, personas, user stories, sitemap, wireframe and repo scaffoldLab 01
Week 02HTML Foundation & Semantic Structure
HTML5		Create meaningful page regions and build web pages using appropriate structural elements.Semantic homepage and planned page regionsLab 02
Week 03Forms & Visual Design Basics
HTML5CSS3		Implement user data collection and apply visual design principles to control user attention.Trip form plus typography, colour and spacing systemLab 03
Week 04Layout Systems (Flexbox & Grid)
CSS FlexboxCSS Grid		Manage one-dimensional and two-dimensional layouts for complex page sections.Flexbox navigation, aligned forms and Grid destination cardsLab 04
Week 05Responsive Design
CSS Media Queries		Adapt the website interface to function across various device screen sizes.Mobile-first layouts and tested breakpointsLab 05
Week 06JavaScript & DOM Interaction
JavaScriptDOM		Add behaviour to a page by connecting programming logic to user actions via the DOM.Interactive mobile navigation and state-based UI behaviourLab 06
Week 07Advanced Forms & Storage
JavaScriptWeb Storage API		Implement client-side validation and persist lightweight user choices between browser sessions.Validation feedback plus persisted lightweight preferencesLab 07
Week 08Dynamic Data & Fetch API
JSONFetch APIJavaScript		Decouple content from structure by loading and rendering dynamic external data.JSON-backed destination cards, filters, loading and error statesLab 08
Week 09UX, Accessibility & Testing
AccessibilityUXValidation		Ensure the site is usable for people with different abilities and optimized for interface quality.Keyboard support, accessible labels/focus and quality evidenceLab 09
Week 10Web Storage
localStorageJSON		Persist lightweight user preferences between browser sessions.Persistent favourites/theme with safe recovery and resetLab 10
Week 11Data Rendering
JavaScriptJSONFilters		Load and render dynamic content from external data sources.Reusable rendering function, filtering and robust interface statesLab 11
Week 12UX & Testing
TestingAccessibilityPerformance		Ensure the site is accessible, validated and optimized for performance.Test report, validation evidence and resolved high-impact defectsLab 12
Week 13Deployment & Release
GitGitHub Pages		Publish a production-ready website to a live public URL.Published GitHub Pages site, final README, test evidence and demonstrationLab 13

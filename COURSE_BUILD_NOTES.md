# Course Build Notes

This repository was assembled from the supplied IS229 13-week teaching archive and the supplied Morobe Discover progressive project archive.

## Source-aligned 13-week sequence

1. Project Discovery & Planning
2. HTML Foundation & Semantic Structure
3. Forms & Visual Design Basics
4. Layout Systems (Flexbox & Grid)
5. Responsive Design
6. JavaScript & DOM Interaction
7. Advanced Forms & Storage
8. Dynamic Data & Fetch API
9. UX, Accessibility & Testing
10. Web Storage
11. Data Rendering
12. UX & Testing

The interactive course preserves this supplied sequence rather than replacing it with a generic web-development curriculum.

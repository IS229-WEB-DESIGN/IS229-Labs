Code explanation

Read the code line by line

Pattern A · javascript
const menuButton = document.querySelector(".menu-toggle");
const nav = document.querySelector(".site-nav");
menuButton.addEventListener("click", () => {
  nav.classList.toggle("is-open");
});
Pattern B · css
.site-nav.is-open {
  display: flex;
}

What it does → Why it works → Where we use it

  1. document.querySelector
    Finds the first DOM element matching a CSS selector.
  2. addEventListener
    Registers a function to run when a named event occurs.
  3. click
    The event emitted when the button is activated.
  4. classList.toggle
    Adds the class if absent and removes it if present.
  5. .is-open
    A state class CSS can use to reveal the navigation.

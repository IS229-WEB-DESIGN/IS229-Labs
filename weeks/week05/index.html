Code explanation

Read the code line by line

Pattern A · css
img {
  max-width: 100%;
  height: auto;
}
Pattern B · css
@media (min-width: 768px) {
  .card-grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

What it does → Why it works → Where we use it

  1. max-width: 100%
    Prevents an image from becoming wider than its container.
  2. height: auto
    Preserves the image's aspect ratio.
  3. @media (min-width: 768px)
    Applies enhanced layout rules only when the viewport is at least 768px wide.
  4. repeat(3, 1fr)
    Changes the card layout to three equal columns at the breakpoint.

Project connection: This code belongs to the Week 05 Morobe Discover increment and should produce a visible or testable change related to Mobile-first layouts and tested breakpoints.

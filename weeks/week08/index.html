Code explanation

Read the code line by line

Pattern A · javascript
const response = await fetch("data/destinations.json");
if (!response.ok) throw new Error("Data failed to load");
const destinations = await response.json();
Pattern B · javascript
const html = destinations
  .map(item => `<article class="card">${item.name}</article>`)
  .join("");

What it does → Why it works → Where we use it

  1. await fetch(...)
    Starts an HTTP request and waits for the response.
  2. response.ok
    Reports whether the HTTP response was successful.
  3. response.json()
    Parses the response body as JSON.
  4. map(...)
    Transforms each data item into a piece of interface markup.
  5. join("")
    Combines the generated strings into one HTML string.

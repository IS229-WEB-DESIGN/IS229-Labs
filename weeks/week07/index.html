Core principle: Validate close to the user and store only lightweight, non-sensitive values in browser storage.
Concept 1

Client-side validation

Improves feedback but does not replace server-side validation.

Concept 2

localStorage

Stores string values across browser sessions.

Concept 3

Safe storage

Avoids private, secret or sensitive information in the browser.

Code explanation

Read the code line by line

Pattern A · javascript
if (days < 1) {
  showError("Trip length must be at least one day.");
  return;
}
Pattern B · javascript
localStorage.setItem("theme", selectedTheme);
const savedTheme = localStorage.getItem("theme");

What it does → Why it works → Where we use it

  1. if (days < 1)
    Checks the business rule before accepting the value.
  2. showError(...)
    Calls a feedback function so the user knows what to correct.
  3. return
    Stops the current function from continuing after an invalid value.
  4. localStorage.setItem
    Stores a key/value pair in browser storage.
  5. localStorage.getItem
    Reads the stored value later.

Code explanation

Read the code line by line

Pattern A · html
<label for="visitorName">Your name</label>
<input id="visitorName" name="visitorName" type="text" required>
Pattern B · css
form {
  max-width: 720px;
  display: grid;
  gap: 1rem;
}

What it does → Why it works → Where we use it

  1. for="visitorName"
    Connects the label to the input whose id is visitorName.
  2. type="text"
    Tells the browser what kind of value the field expects.
  3. required
    Activates built-in required-field validation before submission.
  4. display: grid
    Turns the form into a grid layout container.
  5. gap: 1rem
    Creates consistent spacing between form children.

Project connection: This code belongs to the Week 03 Morobe Discover increment and should produce a visible or testable change related to Trip form plus typography, colour and spacing system.
